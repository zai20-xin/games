# 幻装旅者 · 可玩原型 v0.2

## 怎么玩
双击打开 `index.html`（需要 Chrome/Edge/Safari 等现代浏览器）。

1. **开始界面**：6 套时装点选其一（每套有专属被动，鼠标悬停可预览）
2. **战斗**：WASD / 方向键移动，技能全自动释放，你只负责走位
3. **成长**：捡绿色经验晶体 → 升级三选一（新技能 / 技能升级 / 属性符文），也可按 1/2/3 键选择
4. **目标**：活过 10 分钟，击杀 Boss 即胜利；精英怪掉宝箱 = 直接升 1 级
