# 无限进化

进化主题 Roguelike 无尽生存网页游戏。主角固定中心自动攻击，玩家负责装备/果实策略决策，形态随武器进化（原始人→战士→枪手→机甲→载具→飞行器）。设计文档见 `docs/GAME_DESIGN.md` 与开发计划 `docs/DEV_PLAN.md`。

## 运行

面板启动，或：

```bash
python3 -m http.server 4102
# 打开 http://localhost:4102
```

## 操作

| 输入 | 功能 |
|---|---|
| 点击/触摸 | 开始 / 继续 / 各选择界面交互 |
| P / Esc | 暂停 / 继续暂停 |
| R | 重开一局（对局中、暂停中、结算画面均可） |
| M | 静音切换（持久化到 `localStorage: infinite-evolution:settings`） |
| 右上按钮 | 暂停 |
| 右下按钮 | 释放果实大招（能量满时） |
