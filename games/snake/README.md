# 贪吃蛇

> 状态：**已归档**（2026-08-27）——功能完整可玩，但无迭代计划，保留可玩历史，不再维护。

经典贪吃蛇，纯 HTML/CSS/JS 实现。

## 操作

- 移动：方向键 或 WASD
- 暂停：空格 或 P；重开：R；静音：M
- 技能：加速 / 穿墙（限时）/ 分身（对局内按钮）
- 设置（⚙️）：难度、模式（常规/乱斗）、穿墙模式开关（开启后撞墙从对侧穿出）

## 存档

- 最高分、金币、钻石、皮肤、排行榜、成就统一存 `localStorage` 的 `snake:save`
- 难度 / 模式 / 穿墙 / 静音存 `snake:settings`；旧版散装键自动迁移，无需重置进度
