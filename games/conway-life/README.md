# 生命游戏 · 宇宙许愿池（conway-life）

康威生命游戏（Conway's Game of Life）网页版：零依赖、移动优先，`index.html` 双击即玩（css/js 多文件普通 script 顺序加载，无构建）。

## 玩法

- **许愿**：首屏写下心愿（可填生日、可填首字母），按住屏幕为宇宙注入能量，看混沌凝出一个属于你的符号
- **光爆成卡**：凝形瞬间全屏光爆，随后弹出「宇宙之卡」——发光符号 + 你的原话 + 签文 + 主题色系 + 字母印章，一键保存 PNG 分享
- **专属**：填生日的人，同一天生日会凝出**一模一样**的宇宙（"你是几月几日的宇宙？"）；首字母作为卡的签名印章
- **记住你的愿望**：许愿后宇宙带着你的愿望基调继续演化——许了爱意，后续更常凝出爱心/花朵/月亮
- **看**：细胞按 B3/S23 规则生灭；整片宇宙安定后，流星会砸下来重燃生机
- **收集**：右下角符号盒（30 个符号：数字 0–9 + 爱心/星星/四叶草/皇冠/猫脸/烟花…），凝出/放置即点亮

## 操作

| 键 | 作用 |
|---|---|
| 空格 | 播放 / 暂停 |
| N | 单步一代 |
| R | 随机一片 |
| C | 清空网格 |
| Esc | 取消放置 / 关弹层 / 关宇宙之卡 |

底部 dock：播放/暂停 + 速度滑块（1–1000×，指数映射）。顶栏「主题」切换星野/霓虹/复古/纸白。播放中按钮显示暂停图标、暂停时显示播放三角。仅支持手机竖屏（横屏会提示转正）。

## 结构

```
index.html     壳：DOM 结构 + css/js 引用
css/style.css  样式（四主题色板 + 许愿卡 + 宇宙之卡）
js/engine.js   纯逻辑引擎（Life 规则 / 30 符号 / 识别 / 种子 PRNG / 心愿映射 / 主题表 / 签文库 / A–Z 字模）
js/app.js      运行时（仿真 / 渲染 / 流星 / 凝形 / 许愿仪式 / 宇宙之卡 / 交互）
```

## 运行

```bash
python3 -m http.server 4118   # 端口以 game.json 为准
```

或直接双击 `index.html`（localStorage 进度按浏览器记录）。

## 测试

```bash
node --test test/life-engine.test.mjs   # 引擎单测（直接加载 js/engine.js）
node test/ui-smoke.cjs                  # UI 冒烟（engine+app 拼接 + DOM 桩，零依赖）
```
