# 康威生命游戏（Conway's Game of Life）· 设计方案

> 状态：**已实施完成（v3.2）** —— v2 现代审美 + 大众吸引力、v3 玩法层（首屏演示 / 永不冷场 / 目标挑战 / 图鉴收集）、v3.1 体验打磨（降噪 / 引导 / 空状态 / 连胜成长）、v3.2 底部控制条精简（仅留 播放暂停 + 速度）均已落地；待人工在浏览器/真机复核视觉与触屏体感
> 建立：2026-10-09 ｜ 文档：`docs/life-game-design.md`

---

## 1. 目标与定位

| 项 | 内容 |
|---|---|
| 一句话定位 | 零依赖、可双击打开的网页版生命游戏：**好看、好玩、普通人也看得懂**，可嵌入笔记当"可玩入口" |
| 目标用户 | ① 你自己（嵌笔记）② **完全不懂规则的普通人**（手机上刷到、随手点开） |
| 核心目标 | 规则正确（B3/S23）、渲染流畅（万级细胞 60fps）、**第一眼就美、三秒就能上手** |
| 非目标 | 联机、账号、后端存储、移动端 App 打包 |
| 交付形态 | 单个自包含 `index.html`（内联 CSS/JS，无外部依赖、无构建步骤） |
| 设计基调 | **现代审美 + 大众向**（见 §4，本次新增的核心章节） |

## 2. 核心规则（Conway 标准 B3/S23）

- **存活**：活细胞的 8 邻居中恰有 **2 或 3** 个活细胞 → 下一代存活；否则死亡。
- **诞生**：死细胞的 8 邻居中恰有 **3** 个活细胞 → 下一代复活。
- **边界**：默认 **环面（wrap-around）**，可一键切换为 **死边界**（界外视为死）。
- 规则以常量表 `BIRTH={3}` / `SURVIVE={2,3}` 实现，便于后续开放自定义。
- ⚠️ 术语只出现在「这是什么？」弹层里，**主界面不暴露**（见 §4.2）。

## 3. 功能清单

### P0 — 必做（标准版）
1. **网格渲染**：Canvas 2D，格子尺寸自适应视口，支持 Retina（devicePixelRatio）。
2. **仿真控制**：开始 / 暂停 / 单步 / 清空 / 随机填充（密度由「惊喜我」自动在 0.26–0.34 间变化，不单独暴露密度滑块——移动优先下避免面板噪音）。
3. **速度控制**：1–60 代/秒 滑块。
4. **绘制交互**：指针拖拽连续画细胞；右键或按住 Shift 擦除；支持触屏。
5. **图案库**：点击选中图案 → 在画布落子。内置 10 个（大众化命名见 §4.2）：
   - 振荡器：心跳 / 蛙跳 / 信号灯 / 灯塔
   - 飞船：滑翔机 / 小飞船
   - 静物：石头 / 蜂巢 / 面包
   - 制造机：滑翔机工厂
6. **统计面板**：代数、活细胞数、峰值、FPS。
7. **视觉**：深色主题 + 细胞"年龄着色"，网格线可开关。

### P1 — 增强（**本次纳入**）
1. 环面 / 死边界切换按钮
2. 缩放：格子尺寸 4–24px 调节
3. 主题切换：深色霓虹（默认）/ 手绘复古 / 极简白
4. **大众向体验**（详见 §4）：首屏自动运行、新手引导、「这是什么？」规则动画、图案库实时迷你预览、结构识别彩蛋、一键「惊喜我」
5. **移动端适配**：触屏绘制、双指缩放、竖屏布局、大触控区
6. **无障碍与降级**：`prefers-reduced-motion`、低端设备自动关闭发光层

### P2 — 进阶（**本次不做**，后续按需追加）
1. RLE 图案导入 / 导出（与社区图案互通）
2. 撤销 / 重做
3. 一键导出 GIF / PNG（普通人分享欲的出口，成本较高）

## 4. 现代审美与大众吸引力设计 ★ 本次新增核心

设计原则一句话：**「打开就有画面，三秒就能上手，看一分钟还想再看一分钟。」**

### 4.1 第一印象：拒绝空网格
- 打开页面**自动载入随机 soup 并直接运行**，而不是空白格等用户点。普通人的第一反应必须是"哇"，而不是"我该干嘛"。
- 首屏 3 条微引导气泡（可关闭、可"不再提示"）：
  1. 点一下格子，就能种下生命
  2. 试试右下角「惊喜我」
  3. 空格键随时暂停，慢慢看
- 首屏做一次极缓慢的轻微推近（2 秒、幅度 <5%），制造"活着"的呼吸感。

### 4.2 去术语化：用普通人的语言
- 主界面**不出现** B3/S23、环面、代数等术语；这些折叠进「这是什么？」弹层，配 8 秒动画演示规则（活细胞为什么死、死细胞为什么生）。
- 图案库 = **有画面感的名字 + 一句人话 + 实时迷你预览**：

| 原名 | 展示名 | 一句话说明 | 类型 |
|---|---|---|---|
| Blinker | 心跳 | 原地来回摆动，像心跳 | 振荡 |
| Toad | 蛙跳 | 两排细胞交替翻面 | 振荡 |
| Beacon | 信号灯 | 方阵边缘一闪一闪 | 振荡 |
| Pulsar | 灯塔 | 大范围有节奏地明灭 | 振荡 |
| Glider | 滑翔机 | 会一直斜着飞出去 | 飞船 |
| LWSS | 小飞船 | 横着飞，速度更快 | 飞船 |
| Block | 石头 | 永远不会变 | 静物 |
| Beehive | 蜂巢 | 永远不变 | 静物 |
| Loaf | 面包 | 永远不变 | 静物 |
| Gosper Glider Gun | 滑翔机工厂 | 源源不断造出滑翔机 | 制造机 |

- 每个图案卡片自带 **30×30 实时运行的小预览**（不是静态缩略图）——放之前就知道"它会长成什么样"。

### 4.3 现代视觉语言
- **布局**：顶栏（标题 +「这是什么？」+ 主题）+ 满屏画布 + **底部玻璃拟态悬浮控制条**；图案库做成右侧可收起抽屉（移动端为底部上滑抽屉）。抛弃传统后台式左右分栏。
- **细胞**：年龄着色（新生亮、衰老暗）+ **柔和发光**（主层模糊叠加），形成霓虹质感。
- **平滑过渡（现代感最大来源）**：细胞出生**淡入**、死亡**淡出**（用 age 做 alpha 插值），而不是硬切闪跳——视觉上从"像素跳动"变成"呼吸流动"。
- **微动效**：按钮按下缩放反馈、面板滑入滑出、数值变化轻微位移。
- **字体**：系统字体栈（-apple-system / Inter）；统计数字用等宽字形（tabular-nums）避免跳动。
- **配色**：深色霓虹默认（近黑底 + 青绿→品红的年龄渐变）；另备手绘复古 / 极简白。

### 4.4 发现感与分享欲（留住普通人）
- **结构识别彩蛋**：自动识别并飘字提示——「你造出了一个静物 ✦」「它进入循环了 ✦」「周期 3，它跑不掉了 ✦」。实现成本极低：比较本代与上代 / 上上代即可。
- **一键「惊喜我」**：随机 soup + 自动运行 + 轻微镜头推近，一次点击产出"可看的画面"。
- **数据仪表**：代数 / 活细胞 / 峰值 / 速度，大字克制呈现，像仪表盘一样有即时反馈。
- **后续（P2）**：一键导出 GIF / PNG 分享。

### 4.5 移动端优先（笔记浏览场景）
- 触屏：单指画 / 擦、双指缩放格子、长按擦除。
- 竖屏自动上下布局；控制条固定在底部安全区内；触控区 ≥ 44px。
- 默认视角为**宇宙尺度**（cell=5，全端一致）：格子小 → 同屏几万细胞，`cell<8` 时网格线自动隐藏，干净如星空。
  - 理由：小网格几代就冻成静物/振荡，整屏一重复就弹「进入循环」；大网格要演化几千代才可能安定，更接近「微小扰动在时间长河里一直演化」的真实感（实测：116×66 网格 10/10 在 ~1276 代内整屏安定；280×160 仅 4/10，且推迟到 ~2400 代）。
  - 交互靠拖拽作画 + 图鉴放置，不依赖单格精确点击；用户仍可滚轮 / 双指 / `+` `-` 缩放到 4–24px。

### 4.6 无障碍与降级
- 尊重 `prefers-reduced-motion`：关闭发光与过渡，仅保留静态年龄着色。
- 低端设备自动降级：关闭发光模糊层（保留淡入淡出）。
- 极简白主题面向高对比 / 打印场景；配色做色盲友好校验（红绿不单独承载语义）。

## 6. 技术方案

### 6.1 数据结构
- 双缓冲 `Uint8Array`：`cur` / `next`，长度 `cols*rows`，索引 `idx = y*cols + x`。
- 年龄缓冲 `Uint8Array age`（用于着色与淡入淡出），细胞死亡时衰减而非清零。
- 选择「单字节 + 线性索引」而非 `Array<Array>`：避免 GC 抖动，利于整块遍历。

### 6.2 计算（每代）
- 整行遍历，邻居计数用 `wrap` 取模或边界裁剪（两个分支，避免每格判断）。
- 一次性生成 `next`，然后 `swap(cur, next)`。
- 目标：30000 格单代计算 < 2ms。

### 6.3 渲染
- 离屏 `ImageData`（**每格 1 像素**）+ `putImageData` 到 1:1 小 canvas，再 `drawImage` 放大到主 canvas，`imageSmoothingEnabled=false`。
- 理由：逐格 `fillRect` 在万级格下会掉帧；像素块放大方案可稳定 60fps，且方块观感符合生命游戏气质。
- **淡入淡出**：`age` 参与 alpha 插值，出生从 0→1 淡入、死亡 1→0 淡出（`drawImage` 尊重 alpha，`putImageData` 不尊重，故必须先铺背景再 `drawImage`）。
- **发光**：把细胞层再画一遍并加模糊（`ctx.filter='blur(Npx)'`）叠底，形成霓虹光晕。此项成本较高，**做成可开关**，低端设备自动关闭。
- 网格线单独一层（仅在 cellSize ≥ 8px 时绘制，避免糊成一片）。
- 降级顺序：发光 → 淡入淡出 → 网格线，逐级关闭以保帧率。

### 6.4 主循环
- `requestAnimationFrame` + 时间累加器，按 `gen/s` 节流推进世代；暂停时只渲染不推进。
- 渲染与推进解耦：即使 60 代/秒也能保持画面 60fps。

### 6.5 可测试性设计（关键）
单文件交付物 + 真实单测的冲突解法：引擎代码在 `index.html` 内用标记包裹——

```
/* ENGINE-START */
...纯函数：step() / countNeighbors() / parsePattern() / detectCycle() / PATTERNS...
/* ENGINE-END */
```

`tests/life-engine.test.mjs` 读取 `index.html`、抽取该段、`new Function` 求值后断言。
→ 既保证单文件可移植，又避免"测试用副本"造成的逻辑重复。

## 8. 测试方案（采纳前必须全绿）

引擎层（`node --test`，零第三方依赖）：
1. Blinker 竖线 → 2 代后回到初始形态（周期 2）
2. Block 静物 → 任意代后形态不变
3. Glider → 4 代后整体平移 (+1, +1)
4. 空网格 → 保持全空
5. 死边界下角上孤立细胞 → 按界外为死正确计数
6. 环面下跨边界邻居 → 计数正确
7. 全活 3×3 中心格 → 邻居数 = 8
8. `parsePattern` 对每个内置图案输出正确的活细胞坐标数
9. `detectCycle`：静物判为"稳定"、Blinker 判为"周期 2"、Glider 判为"未进入循环"

手动回归：Chrome / Safari 打开 `index.html`，逐条走 §5 交互表（含触屏与移动端竖屏），确认无控制台报错。

## 11. 玩法层（v3）· 让普通人「看得出乐趣」 ★ 2026-10-09 追加

> 触发：用户反馈「看不出游戏乐趣」。诊断根因有二 ——
> ① 交付物处于**半成品断裂状态**：`frame()` 调用了未定义的 `maybeReseed/runIdentify/tickMission`，`applyTheme()` 引用了未声明的 `dexReady`，页面加载即 `ReferenceError`，主循环直接中断；
> ② 缺少「为什么要继续玩」的目标与反馈。故本次补齐玩法层。

### 11.1 四个乐趣支柱

### 11.5 健壮性优化（2026-10-09 追加）

> 触发：核心算法专项复查。对抗性验证结论——主链路正确：5 万次真实规模（60×40）哈希 0 碰撞、20 个稠密 soup 对飞船/工厂/灯塔 0 误报、灯塔周期 3 正确检出、双缓冲无残留。本次仅做两处零风险健壮性收敛。

| 项 | 原实现 | 现实现 | 理由 |
|---|---|---|---|
| `gridKey` 哈希乘法 | `h * 16777619` | `Math.imul(h, 16777619)` | 乘积最大 9.13e15，略超 `Number.MAX_SAFE_INTEGER`(9.01e15)，存在浮点舍入；`Math.imul` 是教科书式 FNV-1a 的 32 位模乘，零风险 |
| 图鉴计数分母 | 硬编码 `n + '/10'` | `n + '/' + E.PATTERNS.length`，且只统计 `PATTERNS` 内 id | 图案集变动时不再失配，并忽略 localStorage 中的过期 id |

**遗留（未做，另议）**：分组半径 2 会使间距 ≤1 格的独立结构合并后静默漏检（两架滑翔机贴近时 `identify` 返回空，而非计为 1）。真实玩法中工厂喷出的滑翔机间距约 7.5 格，不受影响。

## 17. 流星激活（v3.7） ★ 2026-10-10 追加

宇宙尺度下整屏虽能演化几千代，但终会安定（静物/振荡）。原先仅弹一句「进入循环」，宇宙就此冻结——缺一个把「冷场」变成「惊喜」的机制。

### 17.1 行为口径

- **触发**：`trackStructure` 识别到整屏进入循环/静止（`detectCycle` 返回 `kind`）且距上次提示 > 5 s → 投放 2~3 颗流星。
- **动画**：流星从画布外（上/左/右随机边缘）以 220~380 px/s 斜飞向随机落点，拖尾渐隐 + 白亮流星头，`lighter` 叠发光。
- **撞击**：抵达落点后炸开 6~12 个细胞的一小簇生命（`alpha` 起手 0.3 走淡入），并**重置结构识别**（`S.keys` 清空、`calloutKind` 置 null），让宇宙重新演化。
- **降级**：`prefers-reduced-motion` 下跳过飞行，直接投放生命。
- **不打扰**：演示期（`S.demo`）不触发；沿用「永不冷场」的 `S.autoSeed` 开关。

### 17.2 撞击判定（关键实现细节）

离散步长（220~380 px/s × 16 ms ≈ 4~6 px/帧，高速下更多）会**跳过**「逼近落点 8px」的小窗口，导致漏判、流星永远飞不过去。由于流星匀速直飞落点，速度投影 `dx*m.vx + dy*m.vy` 在落点处过零且随时间**严格单调递增**，故只用 `proj > 0`（已抵达/飞过落点）判定，稳健不漏判。

## 18. 速度档扩到 1–1000×（v3.8） ★ 2026-10-10 追加

原先速度档 1–60×，宇宙尺度下「演化几代」仍偏慢。扩到 1–1000× 让用户能真正把时间长河拉快。

### 18.1 两个关键设计

- **指数映射**：滑块 0–100 → 速度 1–1000×（`10^(pos*3/100)`）。线性 1–1000 会把常用的 1–60 挤进 6% 行程没法精调；指数映射低速段留足行程、高速段照样够到 1000×。
- **时间预算步进**：旧主循环 `guard < 8` 封顶 ~480 代/秒（interval 小到 1ms 时一帧 16ms 只跑 8 代）。改为「本帧最多花 ~14ms 追速度 + 步数上限」双保险，留时间给渲染；追不上就丢弃积压（`acc` 清零）防死亡螺旋。宇宙尺度单代 ~2.7ms，自然封顶在硬件能跑的代数；小网格能真正逼近 1000 代/秒。

## 19. 符号档：有意义的数字与情感符号（v3.9） ★ 2026-10-10 追加

图鉴原有 138 条多是「无意义」的天然结构（用户随机撞见、说不上喜欢）。但很多人玩生命游戏是**带着动机**的——想放个生日年份、想撒把狗粮、想许个愿。故新增「符号」档：20 个**承载意义**的可放置图案，不贪多，先做 20 个。

### 19.1 内容（20 个）

- **数字 0–9**：能拼生日/年份/幸运数，最个人化（如 520、1314、生日）。
- **情感符号 10 个**：♥ 爱心、★ 星星、✓ 对勾、☺ 笑脸、⚡ 闪电、☘ 四叶草、☀ 太阳、✿ 花朵、♦ 钻石、☾ 月亮。

### 19.2 核心技术：block 像素（绕开「Life 里具象形状必塌」的死结）

先前尝试用实心色块画爱心/猫/星，**放上去就塌**（实心区域邻居过载必死），随机搜索也找不到稳定版——这是 Life 规则硬约束，非努力可解。

破局：**用 2×2 block（Life 最稳的静物）当「像素」**，像素间隔 2 格（step=4）分散排布。每个 block 独立、互不干扰，故**任何点阵图形都是永久稳定的静物**（20/20 全部验证通过）。数字、符号想怎么拼都行。

### 19.3 关键取舍：符号不进识别体系，走「放置即收集」

**冲突**：识别系统按连通分量匹配（`findComponents` radius=2），block 像素图案被拆成一堆 2×2 方块——每个方块的指纹都撞上「石头」，导致**画布上任意方块都会被误判成数字/符号**（曾引发演示期误定格 bug）。

**破局**：符号本就是「你主动放置的表达工具」，无需「发现」。故：

- `registry()` 跳过 symbol 档 → 自然扫描不再误匹配（修掉误定格）。
- 放置时 `collectSymbol(pat)` 按 id 直接入账（点亮槽位 + toast，主动放置不打断演化、不触发定格）。
- 许愿列表排除 symbol 档（符号是静态 block，不会从混沌演化出来，选中即死路）。

## §21 混沌凝形：从随机里凝出可辨识符号（垂直切片）★ 2026-10-10

### 21.1 需求重梳（本轮核心转向）

用户重新定位游戏目的：**「通过模拟宇宙随机性来给人惊喜」**。据此推翻上一版「把四叶草/钻石设稀有档、放置时暂停」的方向——手动放置给不了惊喜（符号是用户自己放的，全程掌控、没有失控）。真正的惊艳必须来自**失控**：符号从混沌汤里**自己长出来**，用户第一反应是「这不是我做的，是宇宙做的」。

**什么会惊艳**（按杀伤力）：①脸/眼睛（大脑识形本能）→ ②可辨识物（心/手/鸟）→ ③自我指涉（你的字母/星座）→ ④数学之美（螺旋/分形）。共性=**可辨识 + 对这个人有意义**。

**不同用户不同惊艳** → 个性化三路：开局问一次 / 每局轮换 / 行为自适应。本轮用户选定：**每局随机轮换主题**（结构留好，当前仅一主题故恒定）+ **单主题垂直切片先验证手感**。

**实现前提**：纯随机长不出干净形状（Life 汤几代塌成噪点/闪影），故必须**「引导凝形」**——系统悄悄把目标形状的细胞分批钉进汤里，用户看到的是噪声逐渐锁定成形（魔术的手法）。

### 24.4 v5.2.1 修复：播放/暂停图标不切换 + 速度档消失（2026-10-11）

**现象**（用户真机反馈）：① 开始和暂停按钮没区分；② 速度调整开始后不可见。

**根因**：
1. `setRunning` 用 `el.hidden = true/false` 切 SVG 子元素（`<path id="icoPlay">`/`<g id="icoPause">`）——SVG 元素没有 HTML 的 `hidden` IDL 属性，赋值静默无效，两图标永远同屏 → 按钮看起来"没区分"。改 `setAttribute('hidden','')`/`removeAttribute('hidden')` 走 CSS `[hidden]{display:none}`。
2. 仪式期 `speedWrap.style.visibility='hidden'` 本意是"仪式用固定节奏"，但「再许一愿」路径手工复位 ritual 状态、不走 `exitRitual` → visibility 永不恢复，速度档"开始后"（再许愿/二次仪式）消失。且仪式节奏实为**墙钟驱动**（`tickRitual`/`stepCrystal` 与速度档无关），隐藏控件既无必要又引入泄漏 → **删除隐藏逻辑**，速度档全程可见可调。

**顺手修复**：「再许一愿」改走 `exitRitual()` 统一恢复 `autoSeed`（原路径同样有 autoSeed 永久 false 的泄漏）。

**验证**：冒烟 +2 图标两态断言（boot 暂停态显示播放三角 / 运行态显示暂停图标）、-1 隐藏断言改为"保持可见" → **95/95**；引擎 30/30。

## §25 图形扩充 A+B：30 符号 + 首字母凝形（v5.3）★ 2026-10-11

### 25.1 需求

用户问「现在能出现的图形，是不是只是内置的 20 个图鉴」——确认属实后，选定 **A（扩符号库）+ B（首字母凝形）**：A 解决"就这几个"的广度，B 解决"和我无关"的深度。

### 25.2 A：符号库 20 → 30

新增 10 个 block 像素符号（节日/情感向）：**皇冠**（夺冠/加冕）、**钥匙**（解锁新阶段）、**音符**（听歌/旋律）、**猫脸**（撸猫/宠物）、**蝴蝶**（蜕变/破茧）、**气球**（放飞/飘走）、**雪花**（初雪/浪漫）、**彩虹**（雨后）、**铃铛**（圣诞/祈福）、**烟花**（跨年）。

核心工程改进——`blockRows(logical)` 逻辑图展开器：
- 逻辑图每字符 = 一个 block 像素，展开为 `OO..`/`....`（每字符占 4 列 → **block 间恒隔 2 空格**）、纵向重复 2 行 + 空 1 行。
- 为什么必须隔开：相邻像素若合并成实心 2×N 条（N≥3），中间列邻居 >3 会死，形状塌；隔开后每个 block 都是独立的经典 2×2 静物、互不共享邻居 → **任意逻辑图必为永久静物**。后续加图形只写点阵，不用手算行格式。
- 每个新符号配套：`SURPRISE_WEIGHTS` 权重、`FORTUNES` 签文 3 条、`WISH_RULES` 关键词+theme（追加表末尾，旧映射行为不变）、`WISH_THEMES.symbols` 归组。

### 25.3 B：首字母凝形

- `LETTER_FONTS`：A–Z 5×7 block 字模；`letterPattern(ch)` 小写自动大写、非法返回 null，合成 `{id:'letter_X', letter, rows: blockRows(font), tier:'symbol'}` 一次性图案；`isLetterPattern` 按前缀判定。
- 许愿卡新增选填「我的首字母」（maxlength=1，autocapitalize）；非法字母 toast 拦截。
- `startRitual(text, bday, letter)`：首字母优先为凝形目标（"宇宙专门为你凝出了 K"），心愿仍决定主题加权/签文/色系。
- **字母不入符号盒图鉴**（endRitualToCard 对 letter 跳过 collectSymbol）——图鉴保持 30 个可收集符号的确定性，字母是"只出现一次的宇宙私货"。

## §26 核心体验循环修复：从"等一个形状"到"参与一场仪式"（v5.4）★ 2026-10-12

### 26.1 问题（用户批评，成立）

用户：「你这不是自嗨嘛，用户等半天，就为了显示个字母或者数字呀。」——产品层失败，v5.3 一直在扩图形**广度**（20→30、A–Z），没人质疑核心循环本身：

- **等待 13–17s 被动无参与**：干看细胞乱闪，像加载页
- **高潮缺失**：凝形只是方块慢慢变多，没有"哇"的一刻
- **结果不值一晒**：点阵字母/数字截图缺乏分享价值
- **主角错位**：卡面以点阵图形为视觉中心，但真正该好看的是整张卡

结论：用户要的不是"宇宙里出现了一个形状"，而是"**一张有我名字、好看、能发的海报**"。

### 26.2 四项改造

| 环节 | 改造 | 实现 |
|---|---|---|
| 等待 | **砍半 + 可交互** | 演化 8–12s→**4–6s**、凝形 5s→**2.5s**（`startCrystallize(shape,rng,dur)`）；仪式期**按住屏幕注入能量**：`ritualHold`→`ritualEnergy` 指数平滑（`dt*6` 逼近），驱动三处——有效速度 `speedEff=S.speed*(1+2e)`（细胞 visibly 涌动）、演化进度 `dt*(1+1.5e)`、凝形揭示 `dt*(1+1.5e)`；提示条 `.energy` 呼吸发光 + 轻震动。"你在亲手养一个宇宙" |
| 高潮 | **凝形光爆** | `crystalBurst(x,y)`：110 主题色粒子从符号中心（`S.crystal.cx/cy`→`cellToScreen`）炸开（noGrav 火花四散）+ 双重扩散光环（`S.rings`，半径 `10+t²*900` 加速外扩、透明度衰减）+ `#flash` 全屏径向闪光脉冲（CSS `flashPulse .7s`，渐变中心=符号位置）+ 震动 `[18,40,18]`。光爆 **700ms 后**再出卡（`setTimeout(endRitualToCard,700)`），reduceMotion 全部跳过 |
| 结果 | **卡面海报化** | 点阵退居**背景纹理**（`drawTexture`：符号放大 1.4× 溢出裁切、opacity .07 星图底纹）；符号主视觉改**圆角块 + 大光晕**（roundRect + shadowBlur `scale*2.2`，弱化像素格感）；心愿原话 + 签文 + 主题色系渐变不变 |
| 字母 | **降级为签名印章** | 首字母**不再作为凝形目标**（仪式结果恒为情感符号）；`S.ritualLetter` 只印在卡右上角金色圆章（`.c-stamp` rotate 8°，导出图同款），"这宇宙盖了你的章"而非"宇宙给你写了个 K"。删 `isLetterPattern` 死代码 |

### 26.3 设计原则沉淀

- **等待必须有参与感**：任何 >3s 的加载式体验，要么可交互加速，要么有悬念递进
- **截图欲来自瞬间，不来自静态结果**：把预算花在光爆那一帧，而不是图形库广度
- **广度让位于情绪回报**：30 个符号已够用，再扩符号库是同类自嗨
- **确定性不破**：长按只改"多快看到"，不改"看到什么"（种子 rng 与能量解耦）
