# 像素机甲对决 MECHA DUEL

复古像素风机甲对战小游戏。**回合制格斗**，双方原地站定交替出招。

## 角色

| 角色 | 类型 | 特殊技1 (↓K) | 特殊技2 (↑K) | 超必杀 (→K满能量) |
|---|---|---|---|---|
| 铁拳 | 平衡 | 铁山靠(22伤害+眩晕) | 升龙拳(24伤害) | 真·铁拳(48伤害不可防) |
| 闪电 | 速度 | 雷光拳(17伤害+吸能) | 闪电踢(23伤害无视防御) | 闪电风暴(48伤害不可防) |

## 操作

| 输入 | 动作 |
|---|---|
| `K` / `空格` | 普通攻击 |
| `↓` + `K` | 特殊技1 |
| `↑` + `K` | 特殊技2 |
| `→` + `K` | 超必杀技（需能量满） |
| `J` / `↓`按住 | 敌方回合防御（减伤60%） |

## 规则

- HP 100，每回合双方交替攻击一次
- 速度决定先手概率（速度越高先手概率越大）
- 防御减伤60%，超必杀不可防御
- 特殊技每回合冷却1次
- 三局两胜

## 运行

```bash
python3 -m http.server 4115      # 浏览器开 http://localhost:4115
```

## 测试

```bash
node scripts/_regression.js      # 回合制数值回归测试
```

## 代码结构

单文件纯静态：`index.html` 内含全部 CSS/JS。实现分层：
`CHARACTERS`(角色数据) → `Sound`(8-bit音效) → `Mecha`(状态机+回合制出招+像素绘制) → `EnemyAI`(随机招式) → `FX`(特效) → `Bg`(背景) → `Game`(回合制状态机+角色选择+HUD)。
