# 花园保卫战 · 全新重做设计

> 日期：2026-09-17
> 背景：旧版「5 母本底栏杂交」完全不可玩——战场 90% 空、Lv4+ 贴图巨大遮挡、五粉+露珠信息过载、无位置策略。
> 本稿基于同类塔防调研 + 实机截图诊断，改为经典**网格种花**塔防。

## 1. 调研结论（驱动重做）

| 成功要素 | 旧版问题 | 本作对策 |
|---|---|---|
| 位置 > 数量 | 只能养 5 株固定母本 | 5×6 网格自由种植 |
| 10s 内有反馈 | 开局空窗、怪太小 | 开局 150 花粉 + 2s 首阳光 + 首波 4s |
| HUD ≤3 数字 | 五粉/露珠/母本/波次全上 | 花粉 · 心心 · 波次 |
| 主操作拇指热区 | 进化面板在底部但语义复杂 | 底栏卡牌点选→点格种植 |
| 视觉软决策硬 | 贴图失控、特效散乱 | 固定显示尺寸 + 升级光环仪式 |

## 2. 一句话循环

**选花卡 → 种在格子上 → 挡住宠物 → 拾阳光升级/多种 → 心心耗尽结束。**

- 0–10s：点月季种下，立刻开火
- 10–40s：种荷花产阳光，扩种第二列
- 1–3min：升级月季/补减速，见大波
- 3min+：无尽爬坡，挑战纪录

## 5. 玩法

### 5.1 花（5 职能）

| 花 | 种子 | 定位 | 数值基线 Lv1 |
|---|---|---|---|
| 月季 | 50 | 单体输出 | atk 28 / 1.0s |
| 水仙 | 75 | 减速 | atk 14 / 1.3s + 50% 减速 |
| 海棠 | 100 | 双发 | atk 14×2 / 1.2s |
| 荷花 | 125 | 经济 | 自动产种子 18 + 花粉 12 / 4.8s |
| 兰花 | 150 | 光环辅助 | 周围友军 atk +15% |

**经济（去 PvZ 化）**：
- **种子**：种植消耗；击杀掉落 + 荷花产出，**自动入账**
- **花粉**：进化（Lv1→2→3）消耗；击杀掉落 + 荷花产出，**自动入账**
- 无天降阳光、无点击拾取

进化：点已占格 → 花粉花费 = 基础 × (level-1) × 0.7（最多 Lv3）。

### 5.2 宠物

| 宠 | 解锁波 | 特点 |
|---|---|---|
| 猫 | 1 | 均衡 |
| 鸭 | 3 | 慢、皮厚 |
| 狗 | 5 | 快 |
| 仓鼠 | 7 | 死亡分裂×2 |
| 刺猬 | 9 | 高甲慢速 |

行为：沿列向下 → 撞到花则啃咬（花掉血）→ 到栅栏扣 1 心并消失。

### 5.3 经济

- 起始种子 220 / 花粉 30
- 荷花定时自动产出种子 + 花粉（飘字反馈，无需点击）
- 击杀自动掉落种子 + 花粉；连击额外奖励
- 铲子回收 40% 种子

### 5.4 波次

无尽。首波 4.5s，间隔 12s。每 5 波大波（×1.6 数量）。血量/速度随波缓升并软钳制。

难度：休闲/标准/专家（数量、间隔、成长倍率）。

### 5.5 失败

家有 3 心。宠物闯入 -1。0 心结束。

## 6. 特效（Juice 最小集）

1. 种植：绿 puff + 轻震
2. 命中：花瓣粒子 + 伤害飘字
3. 击杀：碎裂 + 微 hitstop + 自动入账飘字（种+ / 粉+）
4. 进化：白闪 + 金环 + 星尘 + 「LvN」
5. 波次 banner：「第 N 波来了」
6. 连击 ≥5：confetti
7. 环境：低密度花瓣飘落
8. 产出：荷花脉冲 + 双资源飘字（无拾取交互）

音效：种植/射击/命中/产出/进化/破心/结束（程序化 WebAudio）。

## 7. UI 信息架构

- **菜单**：大按钮「开始」→ 难度三卡 → 开战
- **局内**：HUD = 心心 · 波次 · **种子 · 花粉**；底栏卡组；暂停
- **结算**：波数/击杀/最佳 + 再来一局/回菜单

删除：阳光拾取、五粉条、露珠按钮、母本进化面板、配方 chips。
