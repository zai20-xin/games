# 情绪下锅

> 丢进去，看它出糗。笑一下，气就少一点。

情绪可以有出口，但**不必马上宣泄**。把惹你的东西丢进锅，看它顶嘴、找借口、变小丑；用恶搞把注意力带走，气自然就下去了。

纯前端 HTML / CSS / Vanilla JS，数据只存本机 `localStorage`，不上传、不诊断、不评判。

## 怎么玩（不用想）

| 一键 | 发生什么 |
|---|---|
| 首页点个词 / 扔进锅 | 立刻开锅 |
| **戳一戳** | 必顶嘴，捏扁 + 飘字 + 锅回弹 |
| **乱炖**（按住） | 锅自己热闹，连招叠加 |
| **焖一会儿** | 盖盖 1 分钟，怨气变香气 |
| **道具坞横滑** | 8 种怪料：老板的饼 / 甲方的嘴硬 / 周一的闹钟 / 过期的梦想 / 打不通的客服 / 点不到的外卖 / 拉通对齐会 / 冷笑话冰块 |
| **够了，出锅** | 荒诞菜名 + 五星鉴定，默认封存 3 天 |

**连招**：2.8 秒内连续动手会升段（小试牛刀 → 行云流水 → 炉火纯青 → 癫狂大厨 → 传说掌勺人）。

**变形**：淡定脸 → 心虚包子💧 → 上头章鱼💢 → 小丑南瓜🎪 → 疯球土豆🔥 → 被做成菜⭐

**小剧场**：道歉火锅、画饼翻车、锅中哲学……
