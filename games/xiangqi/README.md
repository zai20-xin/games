# 亲子象棋

亲子趣味对战中国象棋，PWA 可安装（manifest + Service Worker），支持离线使用。

## 操作

- 打开即玩：点击棋子走子，红黑轮流行棋（双人）/ 人机对战 / 残局闯关 / 教学
- 底栏按钮：♻️ 新局 · ↩️ 悔棋 · 💡 提示 · 🔄 翻转 · 📜 棋谱 · 🎯 残局 · 🎓 教学
- 中途刷新/关闭页面会自动保存对局（localStorage `xiangqi:save`），下次打开自动恢复；终局后自动清除
- 可安装到主屏幕离线使用（Service Worker 网络优先 + 缓存回退，发版即生效）

## 技术备注

- 缓存版本号在 `sw.js` 的 `CACHE` 常量（当前 `chess-v4`），改任何静态资产发版时需同步 bump
- 结构：js/ 下 main.js 为渲染与交互核心（约 1000 行），chess.js 为纯规则引擎
