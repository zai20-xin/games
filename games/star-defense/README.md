# 星际防线 - 太空塔防

> 保卫你的太空基地，抵御外星入侵！

一款基于 Canvas 2D 的太空科幻风塔防游戏，支持多路径、元素克制、塔组合系统、元游戏进展、每日挑战、无尽模式和**对战模式**。

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 游戏模式

### 🏰 塔防模式（经典）

放置防御塔，抵御外星入侵者的波次进攻。包含17个关卡、3种难度、元素克制、塔组合等丰富策略。

### ⚔ 对战模式（新增）

兵营对线模式！放置兵营自动出兵，双方兵力在甬道中相遇战斗，推掉敌方基地即可获胜。

- **4条甬道**：每条甬道独立对线
- **6种己方兵种**：各有独特能力和精致模型
- **敌方波次系统**：每12秒换一波配置，数值随波次递增
- **兵营更换**：可根据敌方配置随时更换兵营（消耗60%能量）
- **点击敌方槽位**：查看敌方兵种属性和增强倍率

## 游戏特色

- **11种防御塔** × **16种敌人**，丰富的策略组合
- **四元素克制系统**：火 > 土 > 风 > 水 > 火
- **21种塔组合效果**：相邻放置不同塔触发独特加成
- **3条升级分支**：每座塔首次升级可选择攻击/经济/防御方向
- **17个关卡**：5个基础关卡 + 12个星座主题关卡（各有独特机制）
- **元游戏进展**：星尘结晶永久升级系统（攻击/经济/防御三条路线）
- **每日挑战**：基于日期种子的随机挑战，全球玩家同题
- **无尽模式**：无限波次，难度指数递增
- **对战模式**：兵营对线，实时策略对抗
- **16个成就**：击杀、策略、挑战、收集、经济五大类
- **新手引导**：首次游戏自动触发交互式教学

### 敌方增强机制

敌方数值随波次递增：
- **HP/伤害** = 基础值 × (1 + 波次 × 0.15)
- **速度** = 基础值 × (1 + 波次 × 0.03)
- **出兵间隔** = 基础间隔 / (1 + 波次 × 0.08)

### 操作方式

1. 点击左侧虚线 **`+`** 槽位 → 弹出兵营选择菜单
2. 选择兵营类型 → 消耗能量放置（最多4个兵营）
3. 点击已有兵营的槽位 → 弹出更换菜单（6折费用）
4. 点击右侧敌方槽位 → 查看敌方兵种属性和增强倍率
5. 能量自动恢复，合理分配资源是关键

## 操作说明

### 塔防模式

- **选择塔**：点击底部卡牌栏选择要建造的塔类型
- **放置塔**：点击地图上的高亮格子（+号标记）放置
- **升级/出售**：点击已放置的塔打开详情面板
- **游戏速度**：暂停 / 1x / 2x / 3x
- **快捷键**：
  - `空格` / `P`：暂停 / 恢复
  - `R`：局内释放选中塔的大招；失败/胜利结算界面秒重开
  - `M`：音效开关（静音状态自动保存，下次启动保持）
  - `ESC`：关闭面板 / 取消选塔
- **失败界面**：`⚡ 秒重开（R）` 按钮或按 `R` 键立即重打当前关

### 对战模式

- **放置兵营**：点击左侧槽位弹出选择菜单
- **更换兵营**：点击已有兵营的槽位
- **查看敌方**：点击右侧敌方槽位查看属性
- **撤退**：点击右上角撤退按钮返回主菜单

## 技术栈

- **Vite 6** - 构建工具
- **Canvas 2D** - 游戏渲染
- **Web Audio API** - 程序化音效生成
- **localStorage** - 存档系统
- **纯 JavaScript (ES Module)** - 零依赖
