# 躺平

《躺平发育 / 猛鬼宿舍》式**单机网页复刻**：选宿舍上床躺平产金币，吃矿脉加成，升级床铺与门，房间里摆炮台/电塔/游戏机，顶住猎梦者（可变身）挠门，每过一夜三选一技能，撑到天亮。

## 操作

| 输入 | 动作 |
|---|---|
| 点击空房 | 选房躺下 |
| 右侧面板 | 升门 / 升床 / 选建筑 |
| 点地图 `+` 槽或「建造」 | 放置机枪/榴弹/激光/电塔/游戏机 |
| 天亮弹窗 | 技能三选一 |
| P / Esc | 暂停 |
| R | 重开 |
| M | 静音 |

触屏可直接点按；小屏会竖向堆叠地图与商店。

## 要点

- **先床后门**：床是持续产金；房间可能刷 **铜矿 / 金矿 / 钻石矿**（床收益 ×1.25–2.1）
- **残血升门**：门血约 30% 时升级，瞬间回满
- **猎梦者**：血量过半或第 4 夜会 **变身**（更痛更快）
- **天亮技能**：勤俭持家 / 躺着赚钱 / 铁门工 / 军火商 / 紧急维修 / 摸鱼结界 / 赖床
- **游戏机**：不攻击，产金 +6/s
- 撑过 **5 夜** 即胜
