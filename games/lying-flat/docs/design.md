## 品类核心循环（本复刻范围）

```
选宿舍 → 上床躺平产金 → 升门/升床/造炮台 → 猎梦者拆门 → 炮台反击
        ↑___________________________________________________|
                         天亮 / 打退猎梦者 → 下一夜
```

首版做成 **单机人机局**：6 间房，1 玩家 + 5 NPC 邻居；撑过 **5 夜** 或击杀最终夜猎梦者获胜；玩家门破则败。

## 忠实对齐项

1. **术语**：鬼统一叫 **猎梦者**；门分档 **木门 → 铁门 → …**；货币 **金币**；胜利条件文案 **天亮**。
2. **床优先**：床是唯一持续产金；升级费指数上升，鼓励先经济后火力。
3. **门升级回满血**：与攻略「残血升级瞬间回满」一致，保留为关键技巧。
4. **邻居 AI**：NPC 会发育；门残血时优先升门，否则升床/造炮——复刻「养鬼」风险的弱化版。
5. **猎梦者压力**：走位拆门；门破吃人变强；目标偏血少门，但有随机换锁。
