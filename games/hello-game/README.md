# 示例小游戏

> 定位：**脚手架模板演示样例**（2026-08-27 明确）——用于演示 `tools/new.mjs` 脚手架与 dashboard 面板联动的样例，**不参与迭代**，不作为正式游戏验收。

演示模板与面板联动的样例，接球玩法

## 操作

- ← → 或 A/D：移动挡板
- 接住小球得分，球会越来越快
- 最高分自动存档（localStorage `hello-game:save`）

## 运行

```bash
node dashboard/server.mjs   # 面板中点「启动」
```
